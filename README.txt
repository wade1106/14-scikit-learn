================================================================================
  Scikit-Learn 八大核心機器學習演算法 — 實戰範例集
================================================================================

本專案以 Python scikit-learn 實作 8 種經典機器學習演算法，
每個範例皆對應一個現實業務情境，可直接執行、無須外部資料檔。

--------------------------------------------------------------------------------
  環境需求
--------------------------------------------------------------------------------

  Python  >= 3.10
  套件    : scikit-learn, pandas, numpy

  建議使用 uv 建立虛擬環境：

    uv venv --python 3.10
    source .venv/bin/activate          # Linux / macOS
    .venv\Scripts\activate             # Windows PowerShell

    uv pip install scikit-learn pandas numpy

  或使用 pip：

    python -m venv .venv
    source .venv/bin/activate
    pip install scikit-learn pandas numpy

--------------------------------------------------------------------------------
  各範例共通流程
--------------------------------------------------------------------------------

  1. 資料準備    — 程式內建構具業務語意的虛擬 DataFrame（或載入 sklearn 內建資料集）
  2. 資料分割    — train_test_split（分群演算法除外）
  3. 特徵預處理  — 需要時進行 StandardScaler 標準化
  4. 模型訓練    — .fit()
  5. 預測展示    — .predict()
  6. 評估指標    — 回歸：MSE / MAE / R-squared
                   分類：Classification Report / Confusion Matrix
                   分群：Silhouette Score / 群中心分析

--------------------------------------------------------------------------------
  演算法速覽與適用場景
--------------------------------------------------------------------------------

  監督式學習 — 回歸（預測連續數值）
    - 簡單線性回歸  : 單一特徵與目標的線性關係，適合快速建立基線模型
    - 多元線性回歸  : 多個特徵聯合預測，適合房價、銷量等多因子場景

  監督式學習 — 分類（預測類別標籤）
    - 邏輯斯迴歸    : 二元分類的首選基線，可輸出機率，適合風控評分卡
    - 支援向量機    : 高維小樣本表現優異，適合醫學影像、文字分類
    - 決策樹        : 規則透明可解釋，適合需要向業務說明決策邏輯的場景
    - 隨機森林      : 決策樹的集成版，抗過擬合能力強，適合大多數表格資料
    - K-最近鄰      : 無需訓練的惰性學習，適合小資料集快速原型驗證

  非監督式學習 — 分群（發現資料中的自然群組）
    - K-Means       : 最常用的分群演算法，適合客戶分群、異常偵測前處理
